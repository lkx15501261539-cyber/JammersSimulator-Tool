Jammers Lab · Mac 启动说明

1. 完整解压新版模拟器到自己的可写文件夹。不要只取出一个启动文件。
2. 安装 macOS 版 Python 3.12（https://www.python.org/downloads/macos/）。
   启动器要求 64 位 Python 3.10 或以上，推荐 3.12。
3. 双击“启动界面.command”：第三问七点六边形 Baseline 2.0。
   双击“start_q4.command”：第四问 1.0，25 点 C/U。
   双击“start_q4_v2.command”：第四问 2.0，左右机会复测。
   窗口左上角的模型选择框可切换已整合的 Q3 三个模型和 Q4 两个版本。
4. 首次在本机 ~/Library/Application Support/JammersLab/venvs/python-3.12
   准备共用环境，并联网安装五个模型需要的依赖。其他 Python 版本使用对应的
   python-主版本.次版本 子目录。依赖检查通过后，以后可以离线启动。
   旧模拟器文件夹内的 .venv 会保留，但默认不再使用，避免桌面云文件读取等待。
5. 窗口打开后点击“开始模拟”。计算完成后可以播放日志或载入示例回放。

Mac 的安全提示

本交付是 Python 源码与 .command 启动脚本，尚未提供开发者签名、公证的 .app。
“Apple 无法验证是否包含恶意软件／无法验证开发者”表示来源未被系统验证，
这不能证明文件有恶意行为，也不能证明它安全。请先核对下载来源与交付内容；
只有确认是自己信任的这份代码时，才按 Apple 官方说明，在“系统设置 →
隐私与安全性”中对该单个项目选择“仍要打开”（该选项是否显示取决于提示类型）。
不要关闭 Gatekeeper，也不要批量移除下载文件的隔离标记。

若提示“将损坏电脑”“包含恶意软件”或文件“已损坏”，先停止运行，保留提示
原文并重新核对来源；不要将它当作普通的“无法验证开发者”直接放行。
Apple 官方说明：https://support.apple.com/zh-cn/102445

常见启动错误

“ModuleNotFoundError: No module named 'PySide6'”表示当前 Python 环境缺少桌面
依赖，并不是上述安全弹窗。新版启动器会在上述本机共用环境中检查并补齐依赖。
从 Q4 入口首次启动也会准备 Q3 所需依赖，之后可直接在窗口切换。
安装依赖时若没有显式设置 PIP_CERT，启动器会使用本机存在的 /etc/ssl/cert.pem
作为证书信任清单，继续进行 HTTPS 证书验证；设置仅影响本次启动进程。
已有的显式 PIP_CERT 设置会保留，不关闭证书验证，也不改变系统配置。
旧的 Q4-code-v1.0 文件夹或过去下载的 ZIP 不会因 GitHub 更新而自动更新；
本说明的启动文件属于新版完整模拟器。

技术用法（在终端中使用自己已核对的源码）

在模拟器目录执行：
  ./启动界面.command --check-only
  ./start_q4.command --check-only
  ./start_q4_v2.command --check-only

这会准备依赖、核验模型并创建离屏窗口后退出，不等待按键。普通启动会显示窗口，
失败时保留退出码，仅在交互终端等待回车。目录可包含中文和空格。

如需显式复用已有环境，设置 JAMMERS_PYTHON 为其 Python 的完整路径，例如：
  JAMMERS_PYTHON="/完整路径/.venv/bin/python" ./start_q4.command

这是主动选择该环境，缺少依赖时会向其中安装；显式选择优先于本机共用环境。
常规启动优先使用本机共用的 Python 3.12 环境，缺少时优先选择系统安装的 3.12，
再按实际 Python 版本创建共用环境。脚本不会自动选择模拟器目录或父目录 .venv。
已有共用环境不兼容时，请先改名备份再重试；脚本不会自动删除或覆盖它。
高级用法可通过 JAMMERS_VENV_ROOT 指定共用环境根目录，通常无需修改。
额外界面参数会转交模拟器，例如：
  ./启动界面.command --replay "examples/q3-v2-demo"

Q4 两个版本共用环境和认证光学兜底，但为独立模型入口，旧入口仍选择 Q4 1.0。
Q4 2.0 实现范围与仍保留的限制见 docs/Q4_V2.md。

# Q4 模型源码副本

这三个源码文件从本次第四问实现的 `CUMCM-2026/code/` 逐字节复制，用于使
单独下载 `JammersSimulator-Tool` 的 `enhanced-mock` 分支也能运行 Q4。

- `q4.py`：Q4 控制器与 REST 客户端。
- `cu.py`：Q4 当前正式 baseline 使用的确定性几何、认证光学覆盖与 C/U 成本模块。
- `第一问.py`：复用 CUMCM-2026 第一问几何源码；没有修改。

Q4 控制器和 C/U 模块来自本次新增实现，不能理解为上游论文仓库原先已有的代码。
第一问来源为 CUMCM-2026 main 快照
`2e04441d7a98e0c0d4257f66d5e8aa58b0af8800`，原文件 Git blob 为
`d080c324e858e247f619c26e402cebc664337bd5`。

`LICENSE` 保留来源仓库原 MIT 许可；`SHA256SUMS.json` 记录副本内容校验值。
`enhanced/q4_adapter.py` 负责模拟器与回放观察适配，模型本身没有因内置打包而修改。
适配器默认使用本目录；旧交付结构在本目录不存在时仍可使用并列的
`CUMCM-2026/code/`。

当前 Q4 的保守最坏情况代价比较会选择已认证的光学收尾路线；内置打包没有改变
该策略，也不增加有关 Q4 最优性的结论。

JammersLab：Q3 v2.0 / Q4 统一模拟器

这是包含模拟器窗口、模型和 Windows 启动入口的新交付包。
您以前下载的压缩包不会自动更新，请使用这份新包。
Baseline_v2.0_七点六边形.zip 是原始模型包，本身不包含模拟器窗口。

Windows 启动
1. 将整个交付压缩包完整解压到一个您有写入权限的文件夹。
   不要在压缩软件里直接运行 .bat，也不要只取出启动文件。
2. 首次启动前安装 Python 3.12（64 位），安装时勾选添加到 PATH。
   首次需要联网下载依赖。这是 Python 源码交付，不是免安装 EXE。
3. 双击“启动界面.bat”，默认打开 Q3 七点六边形 Baseline 2.0。
   “start_q3_v2.bat”同样打开 Q3 v2.0；“start_q4.bat”打开第四问。
4. 点击“开始模拟”。计算完成后，点击“▶ 播放”或拖动时间轴查看。
5. 如果包内包含 examples/q3-v2-demo，可在窗口中打开这个回放目录，
   直接查看已经完成的 Q3 v2.0 场景。

模型与文件
- Q3 v2.0 原包：models/Baseline_v2.0_七点六边形.zip
- Q4 源码：model_sources/q4/（已内置，不需要另找论文仓库）
- 如果包内提供 models/Baseline_v1.0_两模型完整交付.zip，窗口也可运行 v1。
  没有这个旧包时，仍保留 v1 入口，可在窗口手动选择自己的原包。
- DELIVERY_MANIFEST.json：逐文件 SHA-256 和字节数；不包含开发机环境。
- docs/WINDOWS_DELIVERY.md：重新打包方法和交付范围。

启动脚本会在解压目录内准备自己的 Python 环境。若报错，请保留窗口
中的完整错误；不要只把 .bat 拷贝到其他目录，也不要删除原始模型包。

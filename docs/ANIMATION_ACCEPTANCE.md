## 一次完整的手动观看流程

1. 使用已安装依赖的环境启动 `python -m enhanced gui`，或双击 macOS 的
   `启动界面.command`。启动后由用户点击 **开始模拟** 才运行模型。
2. 选择“六边形 7 点”或“螺旋 12 点”，选择原始 ZIP。首次核对可使用
   `uniform`、seed `42`、`baseline_fixed_field`。
3. 点击 **开始模拟**。窗口显示计算进度，计算完成后自动从原点连续播放。
   **停止计算** 可以中断尚在计算的任务并恢复可操作状态。
4. 保持 **近景画面** 和 **动作慢放** 开启，使用默认 20× 或改为 50×。
   移动采用所选速度，测量、切频、清除最多按 5× 播放。例如 50× 行进后遇到
   一次 5 s 测量，该测量会用约 1 s 屏幕时间展示；虚拟耗时仍是 5 s。
   关闭动作慢放后，各动作统一采用所选速度。
5. 点击暂停，确认机身位置、腿部姿态、扫描效果与虚拟时间一起停下；点击
   **单步** 跳到下一个事件完成时刻。空格和右方向键分别对应播放 / 暂停和单步。
6. 将时间轴向前、向后拖动。位置、轨迹、频道、定位和清除结果按选定时刻恢复，
   时间轴回到测量或清除尚未完成时，不保留其未来结果。
7. 开启 **跟随机器狗** 查看局部路线，滚轮缩放或拖动地图；点击 **全域视角**
   恢复圆域全景。切换 **近景画面**、**测点编号**、源图标和接收半径观察信息层。
   地图可用区域较小时，近景会自动隐藏，避免遮住主图。
8. 点击 **导出统计** 保存 CSV。导出的是当前保存日志的整局最终统计，即使此时
   时间轴还在中途也一样。点击 **保存画面** 将当前完整窗口保存为 PNG。
9. 使用 **Replay · 打开日志** 选择含 `events.jsonl` 的单局目录，载入后点击播放。
   Replay 不需要原模型 ZIP 或 Q1 文件，也不会重新计算策略。

完整运行仍保存 `scenario.json`、`ground_truth.json`、`events.jsonl`、
`observations.jsonl` 和 `metrics.json`。Baseline 运行另保留原程序输出、
文件校验及 `reconciliation.json` 统计核对材料。CSV 和截图是额外导出，
不替换这些运行记录。

## 保持原样的模型与当前限制

- Baseline 两个模型的原代码及配置保持原样；动画层只观察运行日志。文件校验和
  原模型输出对账机制保持有效，动画不会为了画面效果修改清除条件或规划路线。
- 模拟器、策略与 UI 仍分层。真值源只供模拟器计算和 UI 观察，策略只收取公开请求
  响应；显示开关、镜头、导出和播放速度不会改变模型输入、虚拟时间或最终统计。
- 本次是 2D 连续动画与交互呈现升级，没有新增第三问探索算法，没有实现 3D 动力学、
  足部碰撞、真实摄影机、真实地形或传感器物理仿真。
- Simulation 仍先计算整局，再按日志连续播放；模型计算阶段显示进度。复杂场景可能
  需要较长计算时间，也可能保留模型原有的未解决目标，不能从 seed 42 的结果推断
  每个场景均能全清除。
- 当前代码采用跨平台 Python / PySide6，并提供 Windows 启动脚本；Windows 尚未
  实机测试，也尚未提供独立 `.exe` / `.app` 安装包。
- 现有批量 CLI 是 Q1 接口演示的分场景统计。真正第三问策略应按
  [ENHANCED.md 的策略接口](../ENHANCED.md#attach-a-genuine-q3-strategy) 接入，
  通过公开响应驱动原有模拟器与观察层；官方规则差异见
  [COMPATIBILITY.md](../COMPATIBILITY.md)。

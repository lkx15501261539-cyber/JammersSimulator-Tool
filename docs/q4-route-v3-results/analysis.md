# Q4 路径约束机会复测：30×7完整结果独立核验

本批210局全部完成。新路径策略相对旧v2减少了这批场景的任务时间和“从未复测”数量，但并未解决首次复测长期等待。七个已测配置中，追加1次、允许绕路5秒的平均总时间最小；不能预设追加2次最优，也不能把本批最小值写成普适最优。

## 数据与核验范围

原始数据为 `experiments/Q4_route_v3_30x7/q4-route-30x7.json`。种子42–47，每个种子分别用于uniform、center-biased、boundary-biased、clustered、repulsive，共30组几何场景。七策略使用相同真值、误差场和初始25点路线。当前Q4 v2与左右夹击是同一条旧v2基线，未重复算成两个独立模型。

重新读取全部actions、observations、decisions及离线ground_truth：核验114609个已接受动作，动作身份、逐步计时、累计移动、换频、复测预算与次数、逐源首次复测延迟、20米成功清除及定向判别均一致。210局没有失败或计数审计错误，原始报告记录源码运行前后哈希未改变。离线真值仅用于上述核验，不重跑或输入在线决策。

## R2/5与旧版、主动Q2的配对结论

对旧v2，R2/5在30场全部更快，平均少4598.26秒。逐场相对降幅的平均为32.31%；先求平均T再算降幅为32.94%，这两个口径不能混用。最小改善是boundary-biased、seed43：9692.01对11082.78秒，少1390.77秒（12.55%）。R2/5自身最大的完整任务时间为repulsive、seed47的12458.77秒。

对主动Q2，R2/5为21场更快、9场更慢；平均少771.89秒，逐场降幅均值7.12%，平均T降幅7.62%。最差相对结果为repulsive、seed45：10521.76对8887.81秒，反而多1633.95秒（18.38%）；最好结果为repulsive、seed44：少3106.28秒（24.60%）。下面列出全部更慢场景，避免只展示均值。

相对旧v2的平均时间变化分解为：移动−3090.90秒、检测+105.67秒、换频+28.57秒、clear尝试−1641.60秒。相对主动Q2则为移动−687.82秒、检测−6.67秒、换频+0.80秒、clear尝试−78.20秒。这些均来自实际动作成本，成功附加时间相同。

实际执行候选的池化J均值：R2/5为99.55米、主动Q2为84.76米；每场执行前已认证的边际移动时间累计均值分别0.57秒与1261.74秒。因此本批确实出现几何评分较差而整个任务较快的现象。但两策略随后进入的状态不同，这不是在相同F下逐点配对的纯J实验。J来自有限候选与示向角采样的纯P直径计算，不是连续最坏情况上界，也不是已求得的连续全局最优。累计局部绕路与全任务移动差也不是同一量，不能直接用1261.74−0.57代替总T差。

R1/5平均T=9175.09秒，R2/5=9359.50秒，R3/5=9378.17秒。预算1→2使每场clear次数减少20.50、认证清除源次84→217，但总移动距离平均增加956.37米，加上检测/换频，最终每场多184.41秒。预算3比2仅多18.67秒，差异约0.20%，不应夸大；本批没有支持“预算越大越快”。
在预算2下，τ=0与5有25/30场任务T相同；τ=20与5有21/30场相同。τ=20平均少43.91秒（0.47%），只在4场更快、5场更慢，其余相同，不能据此认定20秒普遍更优。阈值0/5/20下无复测源次为19/16/13，说明较宽阈值可在少数场景提供更多机会，但本批总体差别很小。

若本轮必须按照已测完整任务时间选择默认，建议 `extra_budget=1, tau_route_s=5, candidate_policy=route`，依据是本批均值最小且30场都优于旧v2。保留预算2作为减少光学尝试的选项；不建议默认增加到3。预算1的τ=0/20并未做交叉比较，故该建议只是七个已测配置内的经验选择，不是联合参数全局最优。本文不修改运行代码配置。

## 定向判别与结论边界

R2/5记录170次C_rx内no_signal判别，涉及106个去重场景源；离线核对全部对应真实定向源。重复判别说明同源可以在多次已认证位置不可见，不意味着106个位置/朝向联合状态已被精确估计。主动Q2为220次/127源，R1/5为72次/72源。
本批所有任务完成、所有真实清除都在20米内，以及114609次计时对账通过，是具体测试证据。它不替代25点覆盖、C_rx认证、光学F/E覆盖与有限终止的数学证明；也没有证明任意场景360000秒以内完成、任意场景优于旧版、或首次复测延迟有小的统一上界。30场只覆盖6个固定种子×5种分布，没有为平均性能附加高斯、独立或概率保证。

下一轮若专门优化“及时复测”，应把等待时间本身作为明确调度目标/约束，再重新冻结代码和重复同场景比较；本轮结果已经足够支持“更多实际机会复测减少光学扫描并在本批降低T”，不足以支持“正常源都会迅速再次测量”。
